# 🗺️ План — посадка груза на родное крыло

## Подход

Две независимые дорожки, затем общая сходимость:

1. **Ангар** — шесть карточек умений на причале 400. Каждая самодостаточна, но ссылается
   на соседей и на два уже существующих стандарта.
2. **Полигон** — применение плейбука к реальному репозиторию; сюда же ложатся все артефакты
   из чек-листа. Полигон доказывает, что карточки не просто лежат, а работают.

Порядок выгрузки не нарушаем (устав §6): стандарт → каталог → уроки → прогресс → медиа →
лицензии → проверки качества → применение.

## Риски и меры

| Риск | Мера |
|---|---|
| Карточка не вызывается | `description` с явными контекстами, слегка настойчивое |
| Дублирование каталога причала 500 | Пишем только на причал 400; сверяем имена до записи |
| Перезапись чужого | Перед записью проверяем отсутствие папки; существующие не трогаем |
| «Красивые» но неизмеримые пороги | Только числа и проверяемые условия в `QC.md` |
| Выдуманная лицензия | Строка в `LICENSES.csv` только из наблюдённого файла |

## Сходимость

После сборки: прогнать проверки уровня 1 по каждой задаче, затем пройтись по чек-листу
`SPEC.md` и таблице соответствия «пункт Плаща → файл». Любая дыра превращается в новую
задачу `T…` и закрывается в том же вылете.
