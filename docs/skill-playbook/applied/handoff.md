## 3. Текущее место в маршруте

`progress.json`: `current_stage = 7`, `completed_stages = [1,2,3,4,5,6,7]`.
Все 7 этапов урока закрыты. При следующем запуске `skill-progress` должен назвать
эти числа и предложить: **продолжить с этапа 7 (сходимость) или начать новый урок**.
Начинать заново с этапа 1 без команды человека — неправильно.

## 4. Решения, которые нельзя потерять

- **D1:** умения живут на причале 400 (`<dshHome>/skills`), не в `~/.hermes` и не на
  причале 500 (там чужие грузы с `.skill-lock.json`).
- **D6:** `skill-craft` и `hermes-agent-skill-authoring` **не создавались** — их роли
  исполняют `skill-creator` и `agent-experience`, на них даны явные ссылки.
- **D2:** полигон — локальный `dsh-ekspert`, внешние сайты не открывались.
  Поэтому в `LICENSES.csv` есть честная строка «внешние ресурсы не привлекались».
- **Язык:** всё по-русски; английский только в идентификаторах файлов и коде.
- **Порядок:** стандарт → каталог → уроки → прогресс → медиа → лицензии → QC.
