# 🎓 Этап 3. Урок с этапами и шагами

> Применение `skill-lessons`. Материал — паттерны P1–P8 из `INGEST.md`.

## Урок

**После прохождения урока пилот умеет превратить любой изученный репозиторий в шесть
применимых умений и полный комплект артефактов, проверив каждый этап измеримым порогом.**

Одно предложение ✅, измеримый результат ✅.

---

## Этап 1. ИНЖЕСТ
Снять метаданные и выделить паттерны, ничего не выдумывая.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 1.1 | Прочитать главные файлы источника через `read`/`glob`/`grep` | Прочитано ≥ 5 источников, пути записаны в `INGEST.md` |
| 1.2 | Извлечь название, автора, лицензию, стек, статистику | Заполнено ≥ 8 полей метаданных, SHA-256 ≥ 1 файла |
| 1.3 | Выделить блоки с паттернами | Список содержит ≥ 5 паттернов с указанием источника |

**Гейт:** этап 2 открывается только после прохождения проверки качества этапа 1.

## Этап 2. КАТАЛОГ
Зарегистрировать умения до того, как применять.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 2.1 | Снять инвентаризацию причалов 100–500 | Все 5 рангов перечислены, дублей имён нет |
| 2.2 | Добавить записи в таблицу каталога | ≥ 1 новая запись, пустых ячеек 0 |
| 2.3 | Проставить фасеты и обновить оба разреза | 3 фасета у каждой записи; счётчики разрезов сходятся |

**Гейт:** этап 3 открывается только после прохождения проверки качества этапа 2.

## Этап 3. УРОК
Разбить материал на этапы и шаги.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 3.1 | Сформулировать урок | 1 предложение с измеримым результатом |
| 3.2 | Разбить на этапы | ≤ 7 этапов, у каждого название и описание |
| 3.3 | Разбить на шаги | 2–5 шагов на этап, у каждого 3 поля |
| 3.4 | Зафиксировать правило гейта | Правило записано дословно, соседи названы |

**Гейт:** этап 4 открывается только после прохождения проверки качества этапа 3.

## Этап 4. ПРОГРЕСС
Не потерять место остановки между вылетами.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 4.1 | Создать `progress.json` | Файл разбирается как JSON |
| 4.2 | Записать 4 обязательных поля | `current_stage`, `completed_stages`, `completed_steps`, `last_updated` на месте |
| 4.3 | Читать при запуске и предлагать продолжить | В ответе названы текущий этап и последний шаг |

**Гейт:** этап 5 открывается только после прохождения проверки качества этапа 4.

## Этап 5. МЕДИА
Выпустить пять самостоятельных носителей.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 5.1 | Написать `ARTICLE.md` | ≥ 1 секция, ≥ 500 символов |
| 5.2 | Собрать `slides.json` | JSON валиден, `slides.length ≥ 1` |
| 5.3 | Нарисовать `enrichment_diagrams/*.svg` | ≥ 1 файл, на каждый есть ссылка из слайдов |
| 5.4 | Заполнить `related_resources.md` | ≥ 1 полная ссылка с подписью |
| 5.5 | Заполнить `related_media.md` | ≥ 1 запись либо явная оговорка об отсутствии |

**Гейт:** этап 6 открывается только после прохождения проверки качества этапа 5.

## Этап 6. ЛИЦЕНЗИИ
Поставить бирку на каждый внешний ресурс.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 6.1 | Проверить лицензию на источнике **до** взятия | У каждого ресурса записано разрешение или отказ |
| 6.2 | Заполнить `LICENSES.csv` | Заголовок + ≥ 1 строка, пустых ячеек 0 |
| 6.3 | Написать `CREDITS.txt` | Файл непуст, есть ссылка и упоминание лицензии |

**Гейт:** этап 7 открывается только после прохождения проверки качества этапа 6.

## Этап 7. ПРОВЕРКИ КАЧЕСТВА
Поставить пороги и закрыть всё двухуровневой проверкой.

| Шаг | Что делать | Критерий завершения |
|---|---|---|
| 7.1 | Определить количественные пороги | 0 порогов со словами «хорошо/достаточно/аккуратно» |
| 7.2 | Добавить гейт между этапами | Правило зафиксировано в `QC.md` |
| 7.3 | Перечислить гард-хуки | 4 хука, у каждого условие и действие |

**Гейт:** завершение урока открывается только после прохождения уровня 2 проверки.

## Правило гейта (зафиксировано дословно)

> **Не переходить к этапу N+1, пока этап N не завершён и не прошёл проверку качества.**
> Разрешение на переход выдаёт `skill-qc`; прогресс фиксирует `skill-progress`.
