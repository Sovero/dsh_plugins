## 7.2 — Гейт между этапами (зафиксирован дословно)

> **Переход к этапу N+1 разрешён только после прохождения всех порогов этапа N.**
> Результат проверки записывается в `progress.json`; непройденный порог = FAIL,
> этап не закрыт.

> **Не переходить к этапу N+1, пока этап N не завершён и не прошёл проверку качества.**

Оба правила прописаны в каждой из шести карточек и в `LESSON.md`.

только по итогам прохождения гейтов. ✅
