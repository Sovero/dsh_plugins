# Тема «Океан» для DSH Desktop

Океан под интерфейсом. Стеклянные поверхности DSH остаются на месте, а под
ними — вода: косяки мелкой рыбы, киты и акулы, медузы, кельп, кораллы и
затонувший корабль на дне. Движение мыши расходится по воде рябью, мелкая рыба
шарахается от курсора, со дна идут пузыри.

Тёмная и светлая схемы. Палитра следует за темой DSH: ночная глубина или
мелкая солнечная вода.

## Что в океане

| Обитатель | Кто это |
| --- | --- |
| Косяки мелкой рыбы | Семь видов, пять глубин, каждая со своим разбросом размера |
| Киты | Синий, горбатый, косатка |
| Хищники | Две акулы, молот-акула, парусник, пила, нарвал |
| Прочее крупное | Дельфин, скат, удильщик, конёк, кальмар |
| Медузы | Три формы колокола, дрейф по глубине |
| Дно | Кельп, кораллы, скалы, затонувший корабль |
| Живое | Водолаз, который ныряет сверху, пузыри со дна, рябь от курсора |

Рыбы идут косяками на разной глубине: чем ниже и дальше, тем темнее силуэт и
меньше размер. Крупные тела плывут медленно — во столько раз медленнее, чем
крупнее. Скорость привязана к размеру особы, а не к общему множителю.

## Установка

Из этого репозитория:

```bash
dsh plugin --profile web add github:Sovero/dsh_plugins#path:dsh-ocean-theme
```

После установки перезапустите DSH Desktop: хост собирает конфигурацию профиля
при старте. Удаление:

```bash
dsh plugin --profile web remove dsh-ocean-theme
```

Если подпуть не поддерживается вашей версией DSH, распакуйте архив и
установите из локального пути:

```bash
dsh plugin --profile web add /absolute/path/to/dsh-ocean-theme
```

## Настройки

Панель темы — **Настройки → Общие → Океан**.

- **Океан** — включение и выключение темы целиком.
- **Плотность жизни** — сколько рыбы, медуз и донной живности в кадре.
- **Яркость воды** — общая светлота сцены.
- **Сборка** — метка версии плагина. По ней видно, какая сборка загружена.

Настройки переживают перезапуск и применяются без перезагрузки окна.

## Как это устроено

Тема разделена на две половины.

**`lib/index.js` — хост.** Ничего не делает и ни к одному сервису не
обращается. Она нужна только для того, чтобы пакет опознался загруженным и его
браузерная часть попала в склейку. Обращение к сервису без объявленного inject
роняет монтирование целиком вместе с браузерной половиной — в журнале остаётся
одна строка вендора, а снаружи это выглядит как «плагин сломался».

**`lib/client.js — браузер.** Вся картина: слой `.dsh-ocean-layer` с
`z-index: -1` внутри изолированного контекста `body`, поверх него — `#root`,
которому плагин возвращает прозрачность. Слои вставлены отдельным элементом, а
не фоном документа: оболочка кладёт непрозрачный фон на `#root`, и картинка на
`html, body` оказалась бы за ним.

Живой слой — настоящий `<canvas>` внутри слоя. На нём рисуются курсорные
ряби, пузыри и водолаз. Статичная часть (рыба, дно, медузы) — SVG-сцена,
которая пересобирается при смене темы или настроек и кэшируется как фон.

## Проверка

```bash
npm run check
```

Собирает сцену в файл `scene.svg` и печатает её размер, число тел и слушателей.
Сцена после этого — обычный XML, её можно открыть в браузере и посмотреть.
