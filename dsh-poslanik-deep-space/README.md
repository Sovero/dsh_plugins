# `dsh-poslanik-deep-space` — тема «Глубокий космос»

Космическая тема для DSH Web: под текстом интерфейса живёт глубокий космос —
мерцающие звёзды трёх глубин, объёмные туманности, узнаваемые созвездия с
силуэтами-подсказками, планеты с горными городами на ночной стороне, спутниками
и собственной гравитацией, корабли с инерцией, кометы трёх типов и метеориты.
Космос отвечает на работу агента: двойная звезда при генерации, вспышка по
завершении, красный отсвет у чёрной дыры при ошибке. Движение мыши вносит
лёгкое электромагнитное возмущение.

Тема сделана по образцу [dsh-official-homepage-theme](https://github.com/JohnnyTing/dsh-official-homepage-theme):
слоты, токены и собственный слой вместо правок чужой разметки.

## Как это устроено (и почему не ломает интерфейс)

- Разметка приложения не трогается. Плагин добавляет **один** `div.pds-space`
  с канвасом; тема живёт под атрибутом `html[data-poslanik-deep-space]`.
- Слой: `position: fixed; inset: 0; z-index: -1; pointer-events: none`.
  Содержимое интерфейса поднимается правилом `#root { z-index: 10; background: transparent }`
  — так же, как в официальной теме.
- Палитра задаётся токенами `--dsw-alias-*` на `documentElement` и `body`;
  прежние значения возвращаются при dispose.
- Настройки принадлежат хосту: `Config` в `lib/index.js` (volatile-поля),
  панель — в подвале левой панели через слот `sidebar.footer.action`
  (якорное выпадающее окно, а не пункт списка панелей: список панелей
  открывает большую область `main`, а выпадающего окна там нет).
- `prefers-reduced-motion` → один статичный кадр; `visibilitychange` → остановка цикла.
- Никаких `MutationObserver` и никаких правок `position`/`z-index` чужим
  элементам: именно это в первой версии уводило интерфейс в пустоту.

## Установка

Из GitHub:

```bash
dsh plugin --profile web add github:<владелец>/dsh-poslanik-deep-space
```

Из локального пути (при разработке):

```bash
dsh plugin --profile web add /absolute/path/to/dsh-poslanik-deep-space
```

Пакет несёт конфигурацию bundle, поэтому при установке плагин сам попадает в
профиль и начинает загружаться. Удаление:

```bash
dsh plugin --profile web remove dsh-poslanik-deep-space
```

После установки — перезапуск DSH Desktop: хост собирает конфигурацию профиля
при старте, живая перезагрузка не всегда подхватывает новый плагин.

## Проверка и версия

```bash
npm run check                 # синтаксис, согласованность версий, тесты
npm run version:set -- 1.2.0  # версия в package.json и dsh.plugin.json сразу
```

Сборки нет: клиентская половина пишется руками как обычный скрипт, сборщик был
бы лишним звеном.

## Настройки

В DSH настройки живут **в левой панели**: пункт «Звёздное небо» с иконкой в подвале
панели (рядом с настройками), по клику открывается выпадающее окно со всеми
переключателями темы. Когда панель свёрнута, остаётся только иконка. Панель
двуязычная: переключатель **Auto / Русский / English** в верхней строке окна,
выбор хранит хост вместе с остальными настройками, поэтому переживает перезапуск.
Английская версия описания — в [README_EN.md](README_EN.md).

Окно — 420 px шириной и до 640 px высотой (но не больше 82 % высоты экрана,
чтобы оно всегда помещалось). Внутри одна колонка: тумблер, значок, подпись и
подсказка стоят в ряд, подпись не переносится по словам, а гибкая подсказка
сжимается первой. Шрифт внутри окна уменьшен: 12 px на подписи тумблеров, 11 px
на подписях ползунков и 10 px на подсказках, кнопках языка и поле выбора.
Прежняя сетка резервировала под текст минимум 220 px и оставляла вторую
колонку, поэтому в окне 340 px общий минимум не помещался: вторая колонка
выдавливала соседей за край, а длинные подписи переносились на три строки.

У каждого параметра свой значок: планета с кольцом, комета, корабль, звезда,
созвездие, солнце с лучами, чёрная дыра, трек мыши, слои, двойная звезда,
язык, яркость, счётчик кадров. В наборе иконок интерфейса нет ни планеты, ни
кометы, ни чёрной дыры, а «Архив» или «Часы» соврали бы, поэтому значки
собственные (`GLYPHS`): один штрих 1.5 px в рамке 16, цвет берётся из
`currentColor`, внешних запросов ноль, из фокуса значок исключён. Выключенный
тумблер гасит не только текст, но и значок — иначе строка выглядела бы
включённой.

Тумблеры: включена, яркость, звёзды и туманности, корабли, кометы и метеоры,
планеты, созвездия, отклик на работу агента, возмущение от мыши, «Под текстом».
Значения хранит хост (`profiles/web/cordis.patch.yml`).

Под созвездиями стоит ползунок «Сколько созвездий: N» (0…14). Число фигур —
такая же настройка темы, как яркость или потолок кадров: она принадлежит хосту
и переживает перезапуск вместе с остальными.

Потолок кадров — выпадающий список рядом с яркостью: выкл / 15 / 30 / 60, по
умолчанию 30. Недобранное время копится, и кадр пропускается целиком, а не
частично, поэтому картина не мерцает наполовину; при 144 Гц это заметно экономит
электричество. Время сцены и интегрирование движений идут по **накопленному**
шагу — иначе при потолке 30 на 60-герцевом экране слои спешили бы вдвое, а
корабли ползли вдвое медленнее.

## Отклик на работу агента

Клиент не знает, какая сессия текущая: ни один сервис ядра этого не отдаёт. Состояние
поэтому собирает **хост** по событиям `api-session/status`, `api-session/error` и
`agent/error`, и отдаёт его клиенту по своему точному маршруту
`/api/dsh-poslanik-deep-space.state`; клиент опрашивает его раз в секунду.

Маршрут — **точный**, а не перехватчик канала `/api`. Перехватчик у канала один
на всё приложение и принадлежит `dsh-api-gateway`: забрав его, плагин ломает его
инициализацию, и весь `/api` начинает отдавать 404, включая создание сессии.
Точные маршруты хранятся в `Map` по пути и прекрасно уживаются между собой.

Тумблер «Отклик на работу агента» гасит мост на стороне хоста. Если канала нет,
тема просто остаётся спокойной и рисуется как прежде.


## Корабли

Положение кораблей интегрируется по кадрам, а не вычисляется от времени, поэтому
у них есть хвост: последние 26 точек рисуются посегментно — у хвоста толще и
ярче, к началу тает. Курс задаётся не накоплением случайных доворотов, а точкой
назначения: корабль выбирает цель в 0.35–1.2 экрана от себя, летит к ней, взял
новую — и снова. Инерция цела: скорость поворота ограничена и пропорциональна
запасу энергии, модуль скорости меняется с ускорением, а не скачком, и нос смотрит
по фактической скорости, поэтому на вираже отстаёт от цели. Пока корабль
поворачивает, вокруг него горит янтарная дуга длиной по заряду.

Точка берётся от корабля, а не от центра экрана, и это не стилистика. Цель от
центра замыкала маршрут вокруг середины неба: корабль возвращался в одни и те же
четверти экрана. От корабля маршрут уходит прочь, и траектория перестаёт быть
кругом.

Прежняя механика копила замысел мелкими доворотами и держала скорость 2–16 px/с.
За тридцать секунд — время, за которое глаз замечает корабль, — он проходил 8 %
ширины экрана и доворачивал раньше, чем успевал уйти из поля зрения. Радиус
дуги при полной энергии равнялся 10–29 px при высоте экрана 1080 px: корабль
физически не мог покинуть своё пятно. Теперь скорость 14–60 px/с, и за те же
полминуты дальний корабль проходит треть экрана.

Вылетев за край, корабль появляется с противоположной стороны, берёт новую цель
и чистит шлейф. Цель берётся заново обязательно: вошедший тем же курсом, каким
вышел, читался бы как замкнутая петля.

## Далёкие облака

Семь больших цветных масс на самом дальнем плане — то, что в настоящем небе
называют скоплениями и туманностями. Прежние туманности остались: это мягкая
дымка радиусом 0.22–0.5 экрана. Облака крупнее, 0.34–0.78 экрана, и читаются
иначе: у каждого плотное ядро, несколько ореолов по краю и звёздная крошка
внутри. Ровный круг читался бы как пятно краски — неровный силуэт из ореолов
и есть то, что делает массу похожей на облако газа.

Переливка здесь не анимация цвета, а движение самого пятна: каждое облако
дышит (радиус пульсирует на 25–60 % с периодом 50–125 секунд) и медленно
покачивается по вертикали. Скорость и фаза у облаков разные, иначе они пульсировали
бы синхронно и картина выглядела бы механической.

Облака рисуются в кадре, а не в кэше полос параллакса. Полосы пересобираются
только при смене размера и dpr — ради скорости: семь полноэкранных градиентов за
кадр это уже не градиенты, а расход. Но в кэше время стоит, и дышащие облака
застыли бы навсегда. Поэтому у них собственный слой в кадре и свой медленный
дрейф — тот же приём, что у созвездий, которые тоже минуют кэш.

Порядок слоёв: газ → облака → яркие звёзды → тела. Ниже тусклых звёзд они не
попадают намеренно: газ приглушает тусклые звёзды, и облака не должны весить
на небе больше, чем настоящие далёкие звёзды.

## Планеты

Планеты живут в пикселях и **подчиняются взаимной гравитации**: масса растёт как
квадрат радиуса, импульс симметричный, притяжение смягчено. Гравитация лишь
искривляет путь, поэтому наезд пресекается жёстко — при пересечении дисков обе
планеты получают одинаковый толчок наружу **и толчок по скорости навстречу
сближению**. Без этой отдачи раздвижение работало как губка: диски расходились,
а импульс внутрь оставался и подпитывал следующее сближение — планеты слипались.
Стартовое разнесение гарантирует отсутствие наезда на первом кадре, когда гравитация
ещё ничего не успела.

## Почему планеты не кружат

Раньше при потолке ускорения 5 px/с² притяжение разгоняло планету втрое от её
собственной скорости. Импульсы строго симметричны, система консервативна — и
захваченная пара честно повторяла орбиту вечно. Круг был не дефектом
отрисовки, а следствием законов сохранения: у консервативной системы нет
механизма выйти из захвата.

Сейчас у модели есть три вещи, которых раньше не было:

- притяжение ослаблено до потолка 0.06 px/с² — путь заметно гнётся, но курс
  не заворачивается;
- **гомеостаз скорости**: модуль скорости плавно подтягивается к крейсерскому,
  так что притяжение и раздвижение больше не уводят темп произвольно;
- **блуждание курса**: медленный случайный поворот вектора скорости. Это
  единственное необратимое воздействие в модели.

Круг ломает **потолок ускорения**, и это видно измерением: гомеостаз и
блуждание по отдельности почти не влияют на возврат (0.944 против 0.950 у
здоровой, 0.919 без гомеостаза), а возврат потолка к 5 сразу даёт круг.
Работают они в связке, но главный рычаг — потолок.

Доля кадров, проведённых в раздвижении, упала с 0.88 до 0.01. Выбросов за
экран — ноль.

### Чем измеряется «не кружит»

Признак взят прямо из жалобы: планета **возвращается туда же, откуда
вылетела**, через заметный лаг. Мера — минимальный по лагам 1–60 с нормированный
сдвиг `|p(t+L) − p(t)| / (средняя скорость × L)`. Прямая даёт ровно 1 при любом
лаге, замкнутая орбита — около нуля на лаге у периода. Первый вариант теста
мерял другое — «насколько путь похож на петлю» — и был плох: на нём **сломанная
модель ловилась хуже здоровой** (медиана 0.45 против 0.08). У меры петли нет
масштаба, и медленный вялый дрейф даёт ту же цифру, что настоящий круг.

Тест фиксирует 40 семян генератора, считает долю окон с возвратом ниже 0.65
и требует **ровно ноль**. Контрольная проверка в том же тесте требует, чтобы
каждый из пяти откатов физики дал ненулевую долю. Мера проверена ломанием
настоящего кода: потолок 5 → 0.45, смягчение 400 → 0.045.

У меры есть честная граница: окно лага держится не больше 60 с — на более
длинном лаге возврат падает у обеих моделей, и разделение исчезает.

## Чем массивнее планета, тем медленнее она едет

Крейсерская скорость обратно пропорциональна радиусу:
`8 × (60 / радиус)`. Планета вдвое крупнее эталонной едет вдвое медленнее.
Отношение именно обратное, а не «минус доля размера» — так падение темпа
держится на всём диапазоне радиусов 34–92 px. Мелкая планета едет около
12 px/с, крупная — около 3. Поверх накладываются множители глубины и ползунка
«скорость планет»: ползунок масштабирует темп, но не ломает закон.

Влетают с разных сторон, но не ближе суммы радиусов друг к другу. У части
планет есть **спутники**: от одного до трёх, у каждого своя орбита и своя
скорость — ближние быстрее дальних, по Кеплеру. Половина орбиты проходит за
диском, половина перед ним, поэтому дальние спутники рисуются до планеты, а
ближние после.

Диск вращается вокруг своей оси, но не двигает источник света: иначе планета
«поплыла» бы освещением. У каменных и ледяных пятна вращаются вместе с осью, у
газовых гигантов полосы остаются параллельными экватору, а их вращение читается
по блику, обегающему полосу. На ночной стороне каменных планет горят **огни
городов**: маска считается в повёрнутой системе координат, у края диска огни
сжимаются и бледнеют.

## Созвездия

Четырнадцать фигур: Медведица, Орион, Кассиопея, Южный Крест, Лев, Скорпион,
Близнецы, Орел, Дракон, Лебедь, Центавр, Пёс Большой, Лира, Персей. Фигуры
узнаются **почерком, а не подписью** — поэтому названий на небе нет.

Под каждой фигурой лежит полупрозрачный **силуэт-подсказка** (альфа 0.075): тот,
кто знает, что это за созвездие, угадает, остальные ничего не заметят. Вся
графика — три примитива (замкнутая область, линия, круг), никаких файлов.

Все звёзды одной фигуры едут **одним и тем же** сдвигом: иначе при движении
фигура расползлась бы и перестала существовать. Дрейф медленный, 0.6 px/с.

### Дальний план

Созвездия лежат в глубине: слой рисуется **первым**, сразу после очистки холста —
под газом, звёздами, солнцами, чёрными дырами и планетами. Фигура никогда не
лежит поверх планетного диска: планеты ближе к зрителю, а созвездия — часть
далёкой звёздной системы за ними. По той же причине фигуры мельче и тусклее
ближних светил: доля неба 0.12, точки × 0.78, общая прозрачность 0.62.

### Сколько созвездий на небе

Настройка `constellationCount` — ползунок «Сколько созвездий: N» под тумблером
«Созвездия». Диапазон 0…14, по умолчанию 8: 0 — пустое небо, 14 — весь каталог.
Показать больше, чем есть фигур, нельзя — лишние значения обрезаются, дробные
округляются, запредельные и нечисловые уходят в значение по умолчанию. Ползунок
появляется только вместе с включёнными созвездиями.

| `dsh.plugin.json` | манифест плагина: `main` и `client.main` |
| `lib/index.js` | host-половина: `Config`, настройки, состояние агентов, маршрут |
| `lib/client.js` | клиент-половина: стиль, слой, движок космоса, двуязычная панель |
| `cordis.patch.yml` | патч загрузчика, вставляющий плагин в профиль |
| `tests/theme.test.mjs` | 41 проверок: манифест, слои, физика, отсутствие ESM, dispose |
| `scripts/check.mjs` | проверка перед публикацией; запрещает пакетные `client.inject` |
| `README_EN.md` | английская версия этого файла |

`dsh.plugin.json` и `package.json` намеренно **не содержат** `client.inject`:
пакета `@deepseek-ai/dsh-client-ui-slots` в поставке DSH нет, и его объявление
роняло клиентскую половину при импорте, а профиль уходил в safe mode. Клиентской
половине достаточно `return { inject: ['slots'], apply }` из модуля.
