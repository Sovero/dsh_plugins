# `dsh-poslanik-deep-space` — тема «Глубокий космос»

Космическая тема для DSH Web: под текстом интерфейса живёт глубокий космос —
мерцающие звёзды трёх глубин, объёмные туманности, узнаваемые созвездия с
силуэтами-подсказками, планеты с горными городами на ночной стороне, спутниками
и собственной гравитацией, корабли с инерцией, кометы трёх типов и метеориты.
Космос отвечает на работу агента: двойная звезда при генерации, вспышка по
завершении, красный отсвет у чёрной дыры при ошибке. Движение мыши вносит
лёгкое электромагнитное возмущение.

Тема сделана по образцу [dsh-official-homepage-theme](https://github.com/JohnnyTing/dsh-official-homepage-theme):
слоты, токены и собственный слой вместо правок чужой разметки.

## Как это устроено (и почему не ломает интерфейс)

- Разметка приложения не трогается. Плагин добавляет **один** `div.pds-space`
  с канвасом; тема живёт под атрибутом `html[data-poslanik-deep-space]`.
- Слой: `position: fixed; inset: 0; z-index: -1; pointer-events: none`.
  Содержимое интерфейса поднимается правилом `#root { z-index: 10; background: transparent }`
  — так же, как в официальной теме.
- Палитра задаётся токенами `--dsw-alias-*` на `documentElement` и `body`;
  прежние значения возвращаются при dispose.
- Настройки принадлежат хосту: `Config` в `lib/index.js` (volatile-поля),
  панель — в общих настройках через слот `settings.general.item`.
- `prefers-reduced-motion` → один статичный кадр; `visibilitychange` → остановка цикла.
- Никаких `MutationObserver` и никаких правок `position`/`z-index` чужим
  элементам: именно это в первой версии уводило интерфейс в пустоту.

## Установка

Из GitHub:

```bash
dsh plugin --profile web add github:<владелец>/dsh-poslanik-deep-space
```

Из локального пути (при разработке):

```bash
dsh plugin --profile web add /absolute/path/to/dsh-poslanik-deep-space
```

Пакет несёт конфигурацию bundle, поэтому при установке плагин сам попадает в
профиль и начинает загружаться. Удаление:

```bash
dsh plugin --profile web remove dsh-poslanik-deep-space
```

После установки — перезапуск DSH Desktop: хост собирает конфигурацию профиля
при старте, живая перезагрузка не всегда подхватывает новый плагин.

## Проверка и версия

```bash
npm run check                 # синтаксис, согласованность версий, тесты
npm run version:set -- 1.2.0  # версия в package.json и dsh.plugin.json сразу
```

Сборки нет: клиентская половина пишется руками как обычный скрипт, сборщик был
бы лишним звеном.

## Настройки

В DSH: **Настройки → Общие → «Космос»**. Панель двуязычная: переключатель
**Auto / Русский / English** в верхней строке, выбор хранит хост вместе с
остальными настройками, поэтому переживает перезапуск. Английская версия
описания — в [README_EN.md](README_EN.md).

Тумблеры: включена, яркость, звёзды и туманности, корабли, кометы и метеоры,
планеты, созвездия, отклик на работу агента, возмущение от мыши, «Под текстом».
Значения хранит хост (`profiles/web/cordis.patch.yml`).

Потолок кадров — выпадающий список рядом с яркостью: выкл / 15 / 30 / 60, по
умолчанию 30. Недобранное время копится, и кадр пропускается целиком, а не
частично, поэтому картина не мерцает наполовину; при 144 Гц это заметно экономит
электричество. Время сцены и интегрирование движений идут по **накопленному**
шагу — иначе при потолке 30 на 60-герцевом экране слои спешили бы вдвое, а
корабли ползли вдвое медленнее.

Скорость дрейфа планет — второй ползунок, рядом с яркостью: 10–200 %, шаг 5,
по умолчанию 100 %. Это множитель `planetSpeed` из настроек хоста (0.1–2). Он
урезает и стартовую скорость, и потолок скорости, поэтому при вдвое меньшем
режиме гравитация не выводит планеты обратно на прежний предел. Вращение
дисков и орбиты спутников не затрагивается — это не дрейф.

## Отклик на работу агента

Клиент не знает, какая сессия текущая: ни один сервис ядра этого не отдаёт. Состояние
поэтому собирает **хост** по событиям `api-session/status`, `api-session/error` и
`agent/error`, и отдаёт его клиенту по своему точному маршруту
`/api/dsh-poslanik-deep-space.state`; клиент опрашивает его раз в секунду.

Маршрут — **точный**, а не перехватчик канала `/api`. Перехватчик у канала один
на всё приложение и принадлежит `dsh-api-gateway`: забрав его, плагин ломает его
инициализацию, и весь `/api` начинает отдавать 404, включая создание сессии.
Точные маршруты хранятся в `Map` по пути и прекрасно уживаются между собой.

Тумблер «Отклик на работу агента» гасит мост на стороне хоста. Если канала нет,
тема просто остаётся спокойной и рисуется как прежде.


## Корабли

Положение кораблей интегрируется по кадрам, а не вычисляется от времени, поэтому
у них есть хвост: последние 26 точек рисуются посегментно — у хвоста толще и
ярче, к началу тает. Смена курса стоит 0.45 энергии, энергия восстанавливается по
0.16 в секунду; скорость поворота пропорциональна запасу, поэтому на нуле корабль
идёт по инерции. Пока корабль поворачивает, вокруг него горит янтарная дуга
длиной по заряду.

## Планеты

Планеты живут в пикселях и **подчиняются взаимной гравитации**: масса растёт как
квадрат радиуса, импульс симметричный, притяжение смягчено. Гравитация лишь
искривляет путь, поэтому наезд пресекается жёстко — при пересечении дисков обе
планеты получают одинаковый толчок наружу. Стартовое разнесение гарантирует
отсутствие наезда на первом кадре, когда гравитация ещё ничего не успела.

Влетают с разных сторон, но не ближе суммы радиусов друг к другу. У части
планет есть **спутники**: от одного до трёх, у каждого своя орбита и своя
скорость — ближние быстрее дальних, по Кеплеру. Половина орбиты проходит за
диском, половина перед ним, поэтому дальние спутники рисуются до планеты, а
ближние после.

Дрейф планет можно замедлить ползунком в панели темы: множитель урезает стартовую
скорость и потолок скорости, поэтому гравитация не возвращает планеты к прежнему
темпу. Само вращение дисков и орбиты спутников остаётся прежним.

Диск вращается вокруг своей оси, но не двигает источник света: иначе планета
«поплыла» бы освещением. У каменных и ледяных пятна вращаются вместе с осью, у
газовых гигантов полосы остаются параллельными экватору, а их вращение читается
по блику, обегающему полосу. На ночной стороне каменных планет горят **огни
городов**: маска считается в повёрнутой системе координат, у края диска огни
сжимаются и бледнеют.

## Созвездия

Четырнадцать фигур: Медведица, Орион, Кассиопея, Южный Крест, Лев, Скорпион,
Близнецы, Орел, Дракон, Лебедь, Центавр, Пёс Большой, Лира, Персей. Фигуры
узнаются **почерком, а не подписью** — поэтому названий на небе нет.

Под каждой фигурой лежит полупрозрачный **силуэт-подсказка** (альфа 0.075): тот,
кто знает, что это за созвездие, угадает, остальные ничего не заметят. Вся
графика — три примитива (замкнутая область, линия, круг), никаких файлов.

Все звёзды одной фигуры едут **одним и тем же** сдвигом: иначе при движении
фигура расползлась бы и перестала существовать. Дрейф медленный, 0.6 px/с.

| --- | --- |
| `dsh.plugin.json` | манифест плагина: `main` и `client.main` |
| `lib/index.js` | host-половина: `Config`, настройки, состояние агентов, маршрут |

| `scripts/check.mjs` | проверка перед публикацией; запрещает пакетные `client.inject` |
| `README_EN.md` | английская версия этого файла |

`dsh.plugin.json` и `package.json` намеренно **не содержат** `client.inject`:
пакета `@deepseek-ai/dsh-client-ui-slots` в поставке DSH нет, и его объявление
роняло клиентскую половину при импорте, а профиль уходил в safe mode. Клиентской
половине достаточно `return { inject: ['slots'], apply }` из модуля.
