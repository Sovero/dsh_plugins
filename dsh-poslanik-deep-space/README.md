# `dsh-poslanik-deep-space` — тема «Глубокий космос»

Космическая тема для DSH Web: под текстом интерфейса живёт глубокий космос —
мерцающие звёзды трёх глубин, туманности, планеты с терминатором и кольцом,
корабли разного размера и скорости, кометы с хвостами, пролетающие метеоры.
Движение мыши вносит электромагнитное возмущение: пространство вокруг курсора
закручивается, светится и расходится кольцами.

Тема сделана по образцу [dsh-official-homepage-theme](https://github.com/JohnnyTing/dsh-official-homepage-theme):
слоты, токены и собственный слой вместо правок чужой разметки.

## Слои

| Слой | Что рисуется |
| --- | --- |
| Фон | градиент `#04060f → #0a0c1e` |
| Туманности | 4–6 радиальных пятен, медленный дрейф |
| Звёзды | 3 слоя глубины, плотность 160/100/50 тыс. на экран, мерцание `sin(t·f+φ)` |
| Планеты | 2–4 сферы, кольцо у второй, дрейф ~1–2 px/с |
| Кометы | 1–2 штуки, хвост с градиентом, синусоидальное покачивание |
| Метеоры | спавн раз в 2.5–9 с, скорость 700–1300 px/с, след 12 % пути |
| Корабли | 5–8 штук, размер 5–27 px, скорость 3–29 px/с, выхлоп и огонь навигации |
| Поле | свечение, силовые дуги и расходящиеся кольца вокруг курсора |

## Как это устроено (и почему не ломает интерфейс)

- Разметка приложения не трогается. Плагин добавляет **один** `div.pds-space`
  с канвасом; тема живёт под атрибутом `html[data-poslanik-deep-space]`.
- Слой: `position: fixed; inset: 0; z-index: -1; pointer-events: none`.
  Содержимое интерфейса поднимается правилом `#root { z-index: 10; background: transparent }`
  — так же, как в официальной теме.
- Палитра задаётся токенами `--dsw-alias-*` на `documentElement` и `body`;
  прежние значения возвращаются при dispose.
- Настройки принадлежат хосту: `Config` в `lib/index.js` (volatile-поля),
  панель — в общих настройках через слот `settings.general.item`.
- `prefers-reduced-motion` → один статичный кадр; `visibilitychange` → остановка цикла.
- Никаких `MutationObserver` и никаких правок `position`/`z-index` чужим
  элементам: именно это в первой версии уводило интерфейс в пустоту.

## Установка

Из GitHub:

```bash
dsh plugin --profile web add github:<владелец>/dsh-poslanik-deep-space
```

Из локального пути (при разработке):

```bash
dsh plugin --profile web add /absolute/path/to/dsh-poslanik-deep-space
```

Пакет несёт конфигурацию bundle, поэтому при установке плагин сам попадает в
профиль и начинает загружаться. Удаление:

```bash
dsh plugin --profile web remove dsh-poslanik-deep-space
```

После установки — перезапуск DSH Desktop: хост собирает конфигурацию профиля
при старте, живая перезагрузка не всегда подхватывает новый плагин.

## Проверка и версия

```bash
npm run check                 # синтаксис, согласованность версий, тесты
npm run version:set -- 1.2.0  # версия в package.json и dsh.plugin.json сразу
```

Сборки нет: клиентская половина пишется руками как обычный скрипт, сборщик был
бы лишним звеном.

## Настройки

В DSH: **Настройки → Общие → «Космос»**. Панель двуязычная: переключатель
**Auto / Русский / English** в верхней строке, выбор хранит хост вместе с
остальными настройками, поэтому переживает перезапуск. Английская версия
описания — в [README_EN.md](README_EN.md).

Тумблеры: включена, яркость, звёзды и туманности, корабли, кометы и метеоры,
планеты, возмущение от мыши, «Под текстом». Значения хранит хост
(`profiles/web/cordis.patch.yml`).

## Корабли

Положение кораблей интегрируется по кадрам, а не вычисляется от времени, поэтому
у них есть хвост: последние 26 точек рисуются посегментно — у хвоста толще и
ярче, к началу тает. Смена курса стоит 0.45 энергии, энергия восстанавливается по
0.16 в секунду; скорость поворота пропорциональна запасу, поэтому на нуле корабль
идёт по инерции. Пока корабль поворачивает, вокруг него горит янтарная дуга
длиной по заряду.
