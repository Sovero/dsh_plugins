# Моды Claude Code от Sovero

Набор из пяти модов для Claude Code, собранный под привычки работы над игрой
RIFTBOUND. Это маркетплейс (`sovero-mods`): в папке лежит
`.claude-plugin/marketplace.json` и пять модов в `plugins/`. Каждый мод — это
хуки на TypeScript (`hooks/register.tsx` плюс чистые функции рядом) и тесты.

| Мод | Команда | Что делает | Версия |
| --- | --- | --- | --- |
| [`pulse`](plugins/pulse) | `/pulse` | Пульс: в строке состояния видно, чем занят Claude и сколько это длится; сообщение о конце долгой команды (от минуты); панель последних двенадцати шагов. | 0.1.0 |
| [`next-step`](plugins/next-step) | `/next-step` | Далее: кнопки «Далее», «Запусти», «Закоммить» над полем ввода, когда Claude закончил ход. Нажатие отправляет готовую просьбу от имени человека. Тексты кнопок меняются в `hooks/steps.ts`. | 0.1.0 |
| [`course`](plugins/course) | `/course` | Курс: приоритеты и правила проекта на виду над полем ввода и в памяти Claude с начала каждой сессии. До двенадцати строк, у каждой папки проекта свой курс. | 0.1.0 |
| [`key-vault`](plugins/key-vault) | — | Ключ в сейф: если в сообщении есть ключ доступа, мод спрашивает, что с ним делать, до отправки. «Убрать в хранилище» шифрует ключ средствами Windows (DPAPI) в `~/.claude/key-vault`, в сообщении остаётся указание, где он лежит. | 0.1.0 |
| [`expert-teams`](plugins/expert-teams) | `/team` | Команды экспертов: `/team dev \| ux \| qa \| sec \| review` включает команду, тимлид ведёт задачу и зовёт экспертов субагентами; `/team off` выключает. Роли и команды описаны в `hooks/teams.ts`. | 0.1.0 |

## Подключение

Склонируйте репозиторий и подключите папку `claude-code-sovero-mods` как
локальный маркетплейс. В `~/.claude/settings.json` это выглядит так (формат
взят из настроек автора):

```json
{
  "extraKnownMarketplaces": {
    "sovero-mods": {
      "source": { "source": "directory", "path": "C:\\путь\\к\\claude-code-sovero-mods" }
    }
  },
  "enabledPlugins": {
    "pulse@sovero-mods": true,
    "next-step@sovero-mods": true,
    "course@sovero-mods": true,
    "key-vault@sovero-mods": true,
    "expert-teams@sovero-mods": true
  }
}
```

Включайте только нужные моды. После правки настроек или кода мода выполните
`/reload-plugins`.

## Безопасность

- Код модов сам не делает сетевых запросов. Единственное, что связано с сетью:
  у ролей аналитика, архитектора и инженера по безопасности в `expert-teams`
  разрешены инструменты веб-поиска и чтения страниц, которыми пользуется
  субагент, а не мод.
- `key-vault` работает только на Windows с PowerShell. Ключ передаётся
  PowerShell через стандартный ввод, а не в командной строке; хранилище
  зашифровано для текущей учётной записи Windows. Если убрать ключ не вышло,
  сообщение не отправляется.
- В файлах репозитория нет настоящих ключей: в тестах `key-vault` образцы
  собираются из частей.
