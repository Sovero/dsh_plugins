# История изменений

Все значимые изменения набора. Формат по
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по
[SemVer](https://semver.org/lang/ru/).

## 0.1.0 — 2026-10-11

Первая публикация набора. До этого моды жили только в локальном профиле автора.

### Добавлено

- **`pulse`**: строка состояния с текущим шагом и временем, сообщение о конце
  долгой команды, панель последних шагов (`/pulse`).
- **`next-step`**: кнопки «Далее», «Запусти», «Закоммить» над полем ввода
  (`/next-step` скрывает или возвращает их).
- **`course`**: приоритеты и правила проекта над полем ввода и в системном
  запросе (`/course`).
- **`key-vault`**: перехват ключа в сообщении до отправки и шифрованное
  хранилище (Windows, DPAPI).
- **`expert-teams`**: команды экспертов `/team dev | ux | qa | sec | review`.
