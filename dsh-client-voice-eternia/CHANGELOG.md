# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-04

Первая версия: диктовка с кнопки микрофона и распознавание на русском языке.

### Добавлено

- **Кнопка микрофона** на панели ввода: нажатие начинает запись, повторное —
  заканчивает и вставляет текст.
- **Захват звука на хосте** через `ffmpeg`: микрофон пишет процесс DSH, а не
  страница. Поэтому диктовка работает и в окне DSH Desktop, где браузерный
  `getUserMedia` заблокирован белым списком разрешений Electron.
- **Распознавание через облако** — русский язык, которого нет у локального
  движка DSH (SenseVoice знает `auto, zh, en, yue, ja, ko`).
- **Полировка текста** той же моделью, что ведёт разговор: убирает оговорки,
  расставляет знаки. Второй настройки модели для этого нет — она бралась бы
  из того же выбора.
- **Готовые задачи полировки**: обычный текст, деловое письмо, рабочая заметка,
  протокол встречи, техническая речь, сообщение в чат, только орфография.
  Выбор задачи подставляет инструкцию, и её можно править.
- **Страница настроек** в общих настройках DSH: распознавание, полировка,
  микрофон, вставка, интерфейс. У каждого поля есть подсказка.
- **Пункт «Voice settings»** в левой панели и та же страница в разделе настроек.
- **Полоса записи без кнопок**: индикатор уровня и распознанный текст.
  Управление — только микрофоном; кнопок «Готово» и «Отмена» нет.
- **Три языка интерфейса**: русский, английский, китайский. Инструкции
  полировки переведены на все три.
- **Список моделей из профиля DSH**: показываются бесплатные модели, уже
  настроенные в разделе «Модели». Отдельно вписывать `id` не нужно.
- **Ключ доступа не попадает в интерфейс**: поле провайдера — это выбор имени
  записи, значение ключа остаётся на хосте.

### Исправлено при разработке

- Пункт в левой панели ронял приложение, если для него не зарегистрирована
  панель `main`: `layout.selectPanel` бросает для неизвестного ключа. Теперь
  пункт и панель ставятся парой.
- Окно настроек пустело целиком, когда подпись ячейки была функцией с
  аргументом: `resolveSlotLabel` вызывает её без аргументов, а исключение
  внутри глушит весь список разделов.
- Русские инструкции полировки показывались в английском интерфейсе: текст
  лежал в коде, а не в словарях.
