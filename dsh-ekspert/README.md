## Эксперт (dsh-ekspert) — каталог предметных экспертов для DeepSeek Harness

**Эксперт** — плагин для DeepSeek Harness: **каталог экспертов на русском языке**, вызываемых как под-агенты через `@` меню.

> Аналог [dsh-expert](https://github.com/jiuaiwo/dsh-expert), но полностью на русском: все имена, описания, интерфейс, документация.

---

### Возможности

| Что нужно | Как сделать |
|---|---|
| **Вызвать эксперта** | В поле ввода наберите `@` → выберите раздел → эксперта → он станет чипом-ссылкой в сообщении |
| **Пусть модель сама выберет** | Напишите «пусть бэкенд-архитектор посмотрит» — модель вызовет `summon_ekspert` |
| **Несколько экспертов сразу** | Модель вызовет `summon_eksperts` (до 8 параллельно, ошибки отдельных не останавливают остальных) |
| **Посмотреть каталог / создать своего** | Настройки → вкладка **Эксперт** → три закладки: **Эксперты** (просмотр, вкл/выкл, скачивание ресурсов), **Разделы** (свои категории), **Навыки** (вкл/выкл навыков модели) |

### Инструменты модели

| Инструмент | Назначение |
|---|---|
| `list_ekspert` | Список включённых экспертов по разделам. Без аргумента — названия разделов и счётчики; с `division` — раскрывает раздел с именами, слагами, описаниями. **Только для поиска**, когда пользователь не назвал эксперта. |
| `summon_ekspert` | Запускает **одного** эксперта. **Возвращается сразу после старта** — не ждёт ответа. Результат придёт позже уведомлением о завершении. **Не пишите подтверждения** — завершайте ход молча после вызова. |
| `summon_eksperts` | Запускает **несколько** экспертов параллельно. Тоже асинхронный. |
| `fetch_ekspert_assets` | Скачивает большие ресурсы эксперта (навыки, справочники, данные) из облака. Персона всегда локальна. |

### Установка

**DSH Web / CLI:**
```bash
dsh plugin --profile web add dsh-ekspert
```

**DSH Desktop:**  
В **Маркете плагинов** найдите `dsh-ekspert` → Установить.

После установки **перезапустите DSH**. Требуется хост DSH `>=0.1.5-rc.1`.

---

### Данные и удаление

- Данные на диске: `~/.eks-team/` (каталог, русские переводы, ваши эксперты).
- Плагин **не ходит в сеть** за данными каталога (только за большими ресурсами экспертов по требованию), телеметрию не шлёт.
- Удаление плагина **не удаляет** `~/.eks-team/` — чистите вручную, если нужно.
